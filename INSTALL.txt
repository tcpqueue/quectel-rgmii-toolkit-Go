SimpleAdmin Go 离线安装包

1. 完整解压压缩包，不要在压缩软件内直接运行。
2. 用 USB 数据线连接已开启 ADB 的模块，一次连接一台待安装设备。
3. 双击 toolkit.bat，等待安装成功。若自动重启，等待设备重新连接。
4. 打开 http://192.168.225.1/ 或模块实际的局域网 IP。
5. 在登录页选择中文、English、Русский 或 العربية，再登录。

Web 默认账号：admin，默认密码：admin。
系统控制台默认账号：root，首次安装初始化密码：admin。
两个密码相互独立，可在系统设置中修改；升级保留已修改的有效凭据。

包内已包含 ADB、ARMv7 程序和离线网页资源，无需安装 Go、Node.js 或 WSL。
已验证 RM520N-EU，其他型号请确认固件兼容性。

其他 WebUI 请先用对应卸载工具清理。本 Go 版本可直接覆盖升级。
卸载本项目请运行 uninstall.bat，卸载会删除应用配置。

如网口访问不便，在本目录打开终端执行：
adb.exe forward tcp:18081 tcp:80
然后打开 http://127.0.0.1:18081/ 。设备重新连接后需重新建立转发。

无设备预览：双击 run_windows_test.bat，使用模拟数据。
